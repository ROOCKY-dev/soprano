## Minecraft 1.21.1 / NeoForge

- Port the upstream 1.21.4 branch (`ee0eb246d`) to Minecraft 1.21.1 and Java 21.
- Target NeoForge 21.1.265; NeoForge is the default and validated loader on this branch.
- Adapt movement input, boats, world height, interactions, loot registries, equipment attributes, shaders, textures, and render hooks to the 1.21.1 APIs.
- Exclude pale oak and eyeblossoms, which do not exist in 1.21.1. Preserve the remaining wood types and recipes.
- Keep Baritone's public API and mod/config identifiers for integrations.

Build with Java 21:

```sh
./gradlew build -Prelease_version=1.3.0
```

Install `dist/soprano-api-neoforge-1.3.0.jar` in a Minecraft 1.21.1 NeoForge instance, replacing Baritone.

Validation: 5,725 unit tests pass, including regression coverage for legacy input flags and slowdown. Isolated NeoForge client smoke tests load both the development build and the optimized API jar, create a flat world, path eight blocks, open the Soprano menu, and shut down cleanly. The optimized jar also resolves stone drops to cobblestone for mining pickup. This is a backport of the 1.21.4 source line, not the newer 26.3 nightly features.
