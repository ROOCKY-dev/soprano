# Soprano 1.3.1 — Minecraft 1.21.1 NeoForge

Backports upstream `26.3` commit `da12c213bffa3448922d136e3db7eb7788991306`, including v1.1.7-nightly.15, to Minecraft 1.21.1 and Java 21. Built for NeoForge 21.1.265.

Includes the latest Soprano routine system and experimental graph editor, redesigned GUI and HUD, branch mining, smooth combat aim, tool wear management, crafting inventory display, and latest gamer automation logic.

Minecraft blocks, items, mobs, and recipes introduced after 1.21.1 are unavailable. The activity notification setting has no effect on 1.21.1. Rendering, input, audio, and loot integration use the target version APIs.

Install `soprano-api-neoforge-1.3.1.jar` in the instance's `mods` folder.

Validation: full Java 21 release build and all 8,762 tests pass. Isolated development and optimized-jar client checks cover world loading, pathfinding, block drops, the latest menu, and a saved routine advancing after a timed wait.
